# David Christianson

I build systems for processing data at scale. I've spent a career moving between data federation, streaming analytics, e-commerce, and AI applications.

Off hours I build for retro hardware because constraints fuel creativity.

### Selected projects
- **[snagboat](https://github.com/DChristianson/snagboat)** — VS Code extension for developers
  using the IDE as their CLI. Watches AI coding agents, normalizes their activity into one
  local event log, and flags loops, churn, stalls, and context pressure. With heuristics
  tuned by replaying real sessions against trusted AI advisors.
- **[vcs-lisp](https://github.com/DChristianson/vcs-lisp)** — a Lisp interpreter
  that runs on the Atari 2600 (6502 assembly, 128 bytes of RAM).
  Featured on Hacker News.
- **[nand2tetris-samples](https://github.com/DChristianson/nand2tetris-samples)** —
  programs for the Hack computer built from first principles.
